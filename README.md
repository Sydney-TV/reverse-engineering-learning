# RE:START 逆向工程学习助手

面向零基础学习者的本地逆向工程课程原型。当前版本实现学习首页，呈现继续学习、学习进度、薄弱知识点、安全实验状态与每日挑战。

## 本地运行

```bash
python -m http.server 8000
```

浏览器访问 `http://localhost:8000`。

首次打开时需要创建一个仅保存在当前浏览器中的学习档案，并完成新手引导。不同学习者的课程进度、答题和错题记录相互隔离。

## 本机数据

- 数据使用带版本号的 `localStorage` 结构保存，不会上传到网络。
- 可点击左下角学习者菜单新增、切换、编辑或删除档案。
- 如需清除开发阶段数据，进入“设置”，点击“清除测试数据并重新开始”；系统会连续两次确认，不会静默删除记录。

## 设计原则

- 只分析项目内置、来源可控的练习程序。
- 一次聚焦一个学习目标，以短课程和可验证练习形成反馈闭环。
- 中文解释与英文术语并列，帮助学习者对应真实工具界面。
- 无网络、无外部调试器时仍可学习基础内容。
