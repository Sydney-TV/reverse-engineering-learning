# RE:START 逆向工程零基础学习助手 MVP

一个无需安装依赖、可离线运行的浏览器学习软件。它通过中文讲解、自动判题、分层提示和安全的汇编状态模拟，帮助零基础学习者理解进制、CPU、寄存器与条件跳转。

## 已实现功能

- 学习首页、学习地图、课程中心、错题本、学习进度、术语词典和设置七个可用页面。
- 三节完整课程：进制基础，CPU/寄存器/MOV，以及 ADD/CMP/ZF/条件跳转。
- 每课包含学习目标、知识讲解、示例、预测题、交互练习、三道课后题、自动判题、三层提示和答案解析。
- 达到合格条件后完成课程并顺序解锁下一课。
- 汇编演示器支持 `MOV`、`ADD`、`SUB`、`CMP`、`JE` 和 `JNE`，显示四个寄存器、ZF、当前行、下一行及中文步骤解释。
- 使用 `localStorage` 自动保存课程状态、分数、答题次数、错题、学习记录和最后学习位置。
- 错题可重新作答，答对后标记为“已掌握”。
- 设置页提供带二次确认的学习记录清除功能。

## Windows 本地运行

项目没有 npm 或 Python 第三方依赖。Windows 10/11 已安装 Python 时，在项目目录打开 PowerShell：

```powershell
py -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以使用：

```powershell
python -m http.server 8000
```

学习记录只保存在打开页面的浏览器中。使用不同端口会被浏览器视为不同站点，因此建议持续使用同一端口。

## 自动化检查

安装 Node.js 后可以运行核心逻辑测试：

```bash
node tests/test_logic.js
```

## 安全边界

- 只使用项目编写的教学数据与指令模拟；模拟器不执行真实机器代码。
- 不提供文件上传，也不会运行任意 EXE。
- 不用于破解商业软件、绕过许可证或安全保护，也不用于分析恶意程序。
- 示例重点是理解程序结构、汇编和调试原理。
